# Dashboard de Ciencia de Datos con Dash - Dataset Iris

## Descripción

Este proyecto consiste en el desarrollo de una aplicación web interactiva utilizando **Dash**, **Plotly** y **Scikit-Learn** para realizar análisis exploratorio de datos (EDA), visualización de indicadores clave (KPIs) y aplicación de modelos de Machine Learning sobre el dataset **Iris**.

La aplicación está organizada mediante pestañas para facilitar la navegación y la interpretación de los resultados, permitiendo explorar el comportamiento de las variables y evaluar modelos de clasificación y regresión.

---

## Objetivos

- Realizar un análisis exploratorio de datos del dataset Iris.
- Construir visualizaciones interactivas mediante Plotly.
- Diseñar un dashboard profesional utilizando Dash Bootstrap Components.
- Implementar un modelo de Regresión Logística para clasificación de especies.
- Implementar un modelo de Regresión Lineal para predicción de variables continuas.
- Evaluar el desempeño de los modelos mediante métricas y gráficos especializados.

---

## Dataset

Se utiliza el dataset **Iris**, uno de los conjuntos de datos más conocidos en Ciencia de Datos y Machine Learning.

### Variables

- sepal_length
- sepal_width
- petal_length
- petal_width
- species

### Especies

- Setosa
- Versicolor
- Virginica

El dataset es cargado dinámicamente desde una URL pública utilizando Pandas.
